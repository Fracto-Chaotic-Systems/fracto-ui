# Welcome soundtrack

`twelve-note-fugue.mp3` is an unmodified copy of the user-provided
`03.TwelveNoteFugue.mp3`, used as the game welcome-screen backdrop.

SHA-256: `fa9c9eaf20092d466a52cb008783d708a9bc9e974f0fac13a0b5a72c29491682`.

Reset starts it from zero; opening text reads the media playback clock rather
than a wall-clock timer. FRACTO appears at audio time 29.66s. Music continues through the landscape introduction and
stops on confirmation or page unmount. No external music service is required.
