# Pinyon Script

`PinyonScript-Regular.ttf` is the unmodified font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/pinyonscript),
downloaded November 25, 2026. Copyright and redistribution terms are in `OFL.txt`.

The game confirmation prompt uses its naturally slanted calligraphy at 42px with
0.14em letter spacing. The font is served locally, without a remote font request.
