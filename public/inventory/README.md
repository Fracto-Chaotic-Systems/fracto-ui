# Inventory runtime assets

Assets inventory loads models and metadata from the asset service through the
UI's transport proxy; this public directory is not its catalog or model source.

`servers/fracto-asset-server/environments/`. No copy refresh is required for the
live inventory. Scale and materials remain provisional in the canonical record.
